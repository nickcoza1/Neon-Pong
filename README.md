# Neon-Pong
Neon-Pong

Neon-Pong is a browser-based arcade Pong game with a futuristic neon aesthetic. It puts a modern spin on the classic Pong formula with smooth gameplay, glowing visuals, and an interactive interface.

Features

Classic Pong-style gameplay

Neon-inspired visual design

Keyboard controls

Fast-paced arcade gameplay

Runs directly in the browser

Lightweight and easy to run

Built with HTML, CSS, and JavaScript, Neon-Pong is a simple project focused on combining classic arcade gameplay with a modern visual style.
